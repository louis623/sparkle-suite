# Pumpkin Pie

Owner-approved October 19, 2026. Community theme PP-01. Renamed from Pie, Please! at the owner’s request; the stable ID remains pie_please.

Approved Higgsfield Seedance 2.5 source, 1280x720, 24fps, silent. A 9.208-second silent sunlight loop. Pause or use reduced motion for a still scene.
Trimmed reference-frame boundary corrections and an eight-frame circular overlap; no stabilization, reversed footage, or optical flow. These are the accepted v4 bytes.

No generation calls occur at runtime. Reduced motion and saved motion-off use the matching still poster; visitor pause, offscreen pause, and failed-video fallback are supported.
