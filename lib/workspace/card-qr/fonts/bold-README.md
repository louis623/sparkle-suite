`<family>/bold/*-Bold.ttf` are static bold instances cut from the bundled variable
fonts with fontTools `instancer` (wght up to 800, other axes at default). Each is
renamed to its own family, "<Family> Bold", so it never changes any existing flyer
text: only the phone number tspan on the text-to-link line asks for it by name
(Louis, Oct 11, 2026). Same OFL license as the source font in the parent folder.
Lato Bold is the upstream static file (OFL), renamed the same way.
