# Build-script assets (not used by the app at runtime)

- `fonts/google/` — Poppins, Lato, Bitter (italic), Pacifico, Gelasio (italic). All Google Fonts under the SIL Open Font License 1.1 (https://openfontlicense.org). Copied from the box font directory.
- `bizcard-src/` — inputs for `../bizcard-mock/`: per-theme QR PNGs and their metadata (`qr.json`, `qr-custom.json`), recolored social icons (`icons/`, Simple Icons, CC0), and the Heather custom frame (`mhf-f0.5.png`, generated in-house).
